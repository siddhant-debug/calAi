01 · Onboarding
First launch. No forms, no fields — a prompt, one line of example, and a rule to write your answer on.
What the screens are protecting
Logging is silent. The entry is the feedback — the agent never replies to a meal you logged, it just appears in the feed.
Nothing speaks first except one weekly weight question — a data prompt, never advice.
Recommendations are pulled. Ask the agent something, it answers in the same thread — it never volunteers a plan.
Each day is its own session. Today only ever shows today; history is a deliberate trip backward, not a scroll.
